# Contributing

Thanks for the interest. This is a small free tool, so the bar is simple.

- Bug reports: open an issue with your phone model, browser and Windows version.
- Camera compatibility: if an app doesn't see Tally Camera, an issue naming the app helps most.
- Design and docs: the mockup sources live in `design/` and render with Node 20 (`npm install`, `node render.mjs all`).

By contributing you agree your contribution is MIT-licensed. No watermark, no paywall — keep it that way.
